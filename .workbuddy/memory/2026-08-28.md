## 通用维表配置（dim_tables / dim_values）功能实现
用户要把"维表"从零散的 `settings.model_providers` JSON 升级为独立、可维护的功能（管理员可前台新建维表、维护取值，并作为下拉数据源；首个落地：模型供应商 provider）。

### 决策（用户确认）
- 数据模型：新建专用表 `dim_tables` + `dim_values`（不用 settings 存 JSON）
- 页面结构：单层，左侧维表列表 + 右侧可编辑表格（AppTable）
- 维表范围：管理员可自由新建/编辑/删除维表及其取值
- 权限：`require_settings_admin`（super_admin / system_admin）

### 后端（ai-chat-server，根 /Users/puppybaby/Desktop/ai-chat-server）
- `db.py`：`SCHEMA` 新增 `dim_tables`/`dim_values`；`_migrate_model_providers()` 把旧 `settings.model_providers` 一次性迁为 `model_provider` 维表后删旧行；`_seed_dim_tables()` 写入 model_provider（20 个供应商）；`_seed_settings()` 移除 model_providers 默认项。
- `schemas.py`：DimTableOut / DimValueOut / DimValueList / DimTableCreate / DimTableUpdate / DimValueCreate / DimValueUpdate。
- `admin.py`：`_get_provider_ids()` 改读 dim 表；新增 `/dim-tables` 全套 CRUD + `/dim-tables/{id}/values` 分页(支持 search/sort/order/enabled) + `/dim-tables/by-code/{code}/values` 下拉接口。
- 注意：`sqlite3.Row` 无 `.get()`，须用 `row["col"]` 直接索引（曾因此 500）。

### 前端（ai_chat_vue）
- `types/admin.ts`：DimTable / DimValue / DimValueList / DimTableCreate / DimValueCreate / DimValueUpdate / DimOption。
- `services/adminService.ts`：fetchDimTables / createDimTable / updateDimTable / deleteDimTable / fetchDimValues / createDimValue / updateDimValue / deleteDimValue / fetchDimValuesByCode（取值 enabled 0/1 → 映射布尔）。
- `components/admin/AdminSettingsDict.vue`：重写（原先空占位）。左栏维表列表(新建/编辑/删除) + 右栏 AppTable 维护选中维表取值(code/name/sort_order/enabled/remark/actions)，行内编辑、新增弹窗、启停开关、排序、enabled 筛选，复用 AdminSettingsBase 样式；`canManageSettings` 只读降级。
- `components/admin/ModelManage.vue`：provider 数据源由 `fetchSettings('model_providers')` 改为 `fetchDimValuesByCode('model_provider')`，空则回退 `DEFAULT_PROVIDERS`(`src/config/models.ts`)。
- `locales/zh-CN.ts` & `en-US.ts`：新增 `console.dimTable.*` 文案。
