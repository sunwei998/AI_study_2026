## 复用知识
- 全局 `input/textarea:focus` 样式会穿透到封装组件内部 `<input>`（特异性 `input:focus` 0,1,1 > `.class` 0,1,0），封装输入类组件务必显式写 `.xxx:focus { box-shadow:none }` 覆盖。
- AppTable 用法要点：列筛选 `filterable + filterType(input/select/checkbox/radio) + filters/filterMethod`；自定义单元格用 `#column-{key}` 作用域插槽 `{row,index,value,column}`；固定列 `fixed:'right'`；外层撑满需 `:deep` 给 wrapper/scroll 设 flex。

## 修复 AppTable 筛选面板"再次点击图标无法收起"的 bug
- 现象：打开某列表头筛选面板后，再次点击同一图标，面板不收起（保持打开）。
- 根因：事件阶段冲突。图标 `@click.stop="toggleFilter"` 只拦截**冒泡**阶段；而 `onFilterDocClick` 用 `document.addEventListener('click', ..., true)`（capture=true）注册，在**捕获**阶段早于图标 `@click` 触发。二次点击同一图标时：捕获阶段 `onFilterDocClick` 先把 `visible` 置 false 并移除监听 → 随后 `toggleFilter` 见 `visible` 为 false 落入「打开」分支，把面板重新打开。
- 修复：在 `onFilterDocClick` 开头加 `if ((target as Element)?.closest?.('.app-table__filter-wrap')) return`，让点击筛选图标本身时交给 `toggleFilter` 处理开关。`toggleFilter` 内 `if (visible && sameCol) closeFilterPanel()` 逻辑已正确，无需改。
- 验证：vue-tsc + vite build 通过。
