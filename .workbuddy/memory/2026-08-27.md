## AppInput 聚焦异常修复（bug）
- 现象：数字输入框聚焦时出现「双层边框 + 发光环」的怪异效果。
- 根因：`src/styles/global.css` 里的全局 `input:focus` 规则带 `box-shadow: 0 0 0 3px var(--color-glow), 0 0 18px ...`，特异性高于组件内 `.app-input__inner`（未写 box-shadow），聚焦时穿透到内部 `<input>` 上。
- 修复：`AppInput.vue` 的 `.app-input__inner` 补 `box-shadow:none; padding:0; border-radius:0`，并新增 `.app-input__inner:focus` 覆盖全局 focus 样式。
- 顺带移除聚焦时 step 内部边框变主色的两段样式（`.is-focused .app-input__step` / `.step-btn:first-child`）。

## 复用知识
- 全局 `input/textarea:focus` 样式会穿透到封装组件内部 `<input>`（特异性 `input:focus` 0,1,1 > `.class` 0,1,0），封装输入类组件务必显式写 `.xxx:focus { box-shadow:none }` 覆盖。
- AppTable 用法要点：列筛选 `filterable + filterType(input/select/checkbox/radio) + filters/filterMethod`；自定义单元格用 `#column-{key}` 作用域插槽 `{row,index,value,column}`；固定列 `fixed:'right'`；外层撑满需 `:deep` 给 wrapper/scroll 设 flex。

## 修复表头筛选图标不显示 + 补回角色筛选
- 现象：用户列表只显示 1 个筛选图标（性别），用户名和角色都没有。
- 根因：`AppTable.vue` 表头筛选按钮条件写成 `v-if="col.filterable && col.filters?.length"`，`filterType:'input'`（用户名）没有 `filters` 数组 → 按钮被隐藏。改为 `v-if="col.filterable"` 即可让 input 类型也显示漏斗按钮。
- 补回角色筛选：role 列加回 `filterable + filterType:'select'` + `filters:[admin,user]`（文案 `console.roleAdmin/roleUser`）。
- 后端 `list_users` 追加 `role` 参数（逗号分隔多选，`u.role IN (?)`）；前端 service `PaginationParams` 加 `roles?: string[]`、`fetchAdminUsers` 拼 `role=a,b`；AdminUsers 加 `roleFilter` 状态并在 `onFilterChange` 里取值透传。
- 最终筛选字段：用户名(input)、角色(select)、性别(checkbox)，全部服务端过滤。

## 修复 AppTable 筛选面板"再次点击图标无法收起"的 bug
- 现象：打开某列表头筛选面板后，再次点击同一图标，面板不收起（保持打开）。
- 根因：事件阶段冲突。图标 `@click.stop="toggleFilter"` 只拦截**冒泡**阶段；而 `onFilterDocClick` 用 `document.addEventListener('click', ..., true)`（capture=true）注册，在**捕获**阶段早于图标 `@click` 触发。二次点击同一图标时：捕获阶段 `onFilterDocClick` 先把 `visible` 置 false 并移除监听 → 随后 `toggleFilter` 见 `visible` 为 false 落入「打开」分支，把面板重新打开。
- 修复：在 `onFilterDocClick` 开头加 `if ((target as Element)?.closest?.('.app-table__filter-wrap')) return`，让点击筛选图标本身时交给 `toggleFilter` 处理开关。`toggleFilter` 内 `if (visible && sameCol) closeFilterPanel()` 逻辑已正确，无需改。
- 验证：vue-tsc + vite build 通过。
