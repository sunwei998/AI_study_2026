🚀 快速开始 (3步)
─────────────────────────────────────────────────────────────────
1. 启动开发服务器
   $ npm run dev
   
2. 修改API地址 (src/services/apiService.ts, 第50-57行)
   baseUrl: 'http://localhost:11434'
   model: 'deepseek-r1:7b'

3. 启动Ollama服务
   $ ollama serve
   $ ollama pull deepseek-r1:7b

🐛 常见问题
─────────────────────────────────────────────────────────────────
Q: 页面样式不显示?
A: 清除浏览器缓存 (Ctrl+Shift+Del)，然后Ctrl+Shift+R刷新

Q: API连接失败?
A: 检查Ollama是否运行 (ollama serve)
   检查地址和端口是否正确
   查看浏览器Console错误信息

Q: 消息丢失?
A: 检查localStorage是否启用
   存储空间是否已满
   清除数据会导致消息丢失

Q: 构建失败?
A: 运行 npm install 重新安装依赖
   检查Node版本 (需要 >= 16)
